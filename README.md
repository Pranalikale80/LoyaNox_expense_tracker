# 💰 Expense Tracker

A simple and responsive Expense Tracker built using **React**, **Vite**, **Tailwind CSS**, and **shadcn/ui**.

## 🚀 Features

* Add new expenses
* Select expense category
* Add description
* Choose expense date
* Responsive and clean UI

## 🛠️ Tech Stack

* React
* Vite
* Tailwind CSS
* shadcn/ui
* Lucide React
